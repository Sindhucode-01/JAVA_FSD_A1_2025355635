# Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my skills, projects, education, achievements, certifications, and leadership experience.

## 🚀 About the Project

This portfolio was created as a simple frontend project while learning and practicing web development fundamentals.

The website presents my academic and technical profile in a clean, modern, and responsive interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Git
- GitHub

## ✨ Features

- Responsive design for desktop and mobile devices
- Navigation bar with smooth scrolling
- Hero section with personal introduction
- About Me section
- Technical and soft skills
- Projects showcase
- Leadership and responsibilities timeline
- Achievements and certifications
- Education and academic performance
- Contact section
- Interactive UI elements using JavaScript
- Scroll animations
- Mobile-friendly navigation
